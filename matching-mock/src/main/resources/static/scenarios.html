确定性场景回放

通过 RabbitMQ 逐步投递，等待引擎可靠回执，校验状态、数量、成交价格和 maker 顺序。每次运行独立生成命令 ID。

使用专用测试交易对，并在 server 启用它。测试价格为 99 / 100 个最小价格单位，数量为 1–3 个最小数量单位。请停止此交易对的其他下单来源，避免干扰。
