◈ BITUAN / MOCK现货撮合测试中心

开始一次撮合测试

先检查交易对参数，再进入交易页面投递订单。

01 / CONFIGURATION

参数配置

查看 20 个交易对，设置模拟下单示例价格。参数保存在 MySQL。

进入参数配置 →02 / SPOT TRADING

现货交易

切换币种，投递限价单、市价单和撤单，查看真实撮合结果。

进入交易页面 →03 / BATCH ORDERS

批量下单

选择交易对、单价和每单数量，一次投递最多 1000 笔相同参数的限价单。

进入批量下单 →04 / BOOK STRATEGIES

盘口策略

每秒跟随币安盘口，仅调整差异档位；支持修改参数和查看关联委托。

进入策略管理 →05 / TRADE REPLAY

对敲策略

跟随币安最新成交，按主动买卖方向投递本地限价 IOC 单，查看实际撮合结果。

进入对敲策略 →06 / SCENARIO REPLAY

确定性场景回放

逐步执行价格优先、时间优先、撤单及 IOC / FOK 场景，自动对照可靠回执。

进入场景测试 →

下单与可靠结果通过 RabbitMQ 传输，盘口与最新成交来自 Kafka。交易对是否启用由 server 引擎配置决定。
